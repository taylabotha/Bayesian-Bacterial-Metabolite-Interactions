
# Bayesian Estimation of Bacterial–Metabolite Interactions

This repository contains the R code used for the project: **"Improving Bayesian Estimation of Bacterial–Metabolite Interactions by Introducing Horseshoe and LASSO Priors."**

The study compares Uniform, Horseshoe, and LASSO priors for estimating bacterial–metabolite interaction coefficients using simulated microbial communities.

The code includes:
- Simulation of bacterial–metabolite interactions using ordinary differential equations (ODEs).
- Bayesian parameter estimation using Uniform, Horseshoe, and LASSO priors.
- Analysis and visualisation of results, including convergence diagnostics and coefficient recovery.

The analyses were conducted in **R**, using **RStan** for Bayesian inference.
